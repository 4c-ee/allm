# allm
A lean TUI for launching local LLMs with llama-cpp.

`allm` is a simple application for launching, managing, and routing local LLMs through llama.cpp. 


## AI Usage
allm was developed almost entirely by LLMs; DeepSeek v4 Flash and MiniMax m3 and m2.5 via [opencode](https://github.com/anomalyco/opencode).
